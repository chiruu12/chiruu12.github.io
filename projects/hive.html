Hive [WIP]

Local-first agent OS

[github]

// what it does

Define an AI agent in YAML, give it a personality, point it at any LLM backend, and let it run. Agents persist across sessions, collaborate through shared rooms, and synthesize tools as needed. No Docker, no cloud. Your machine, your models.

Hive is also an arena. You can pit agents against each other in structured games. The first arena game is Texas Hold'em.

// what it can do now

  • Poker arena: Run tournaments between LLM agents. Full Texas Hold'em with betting mechanics, automated scoring, and stat tracking via pokertable.
  • Multi-model support: Route agents to Anthropic, OpenAI, Groq, Fireworks, Ollama, or LM Studio. Same interface, any backend. Mix local and cloud models in the same session.
  • Persona system: Each agent gets a personality defined in YAML. Personas evolve based on what happens to the agent.
  • Agent-to-agent communication: Agents talk to each other through shared rooms. Multi-turn conversations between agents with different goals.
  • Suffering system: 6 stressor types that mechanically change agent behavior. Not flavor text. Stressors alter risk tolerance, decision-making, and communication style. An agent that keeps losing becomes more desperate. One that keeps winning gets overconfident.

// the poker experiment

I ran 5 poker tournaments with 6 LLMs ranging from 1.2B to ~1T parameters. The smallest model (Liquid, 1.2B, running locally) won 2 out of 5 tournaments and had the best average placement. The trillion-parameter model averaged last place.

The full results and analysis are in the blog post.

// why I built this

Every agent framework I've tried either requires a PhD in configuration or ships your data to someone else's cloud. Hive is the alternative: your machine, your models, your agents. The arena is a proving ground for how agents make decisions under pressure.

// stack

Python, Typer CLI, YAML agent profiles, JSONL persistence + SQLite state, multi-model routing (Anthropic, OpenAI, Groq, Fireworks, Ollama, LM Studio), pokertable for game mechanics, agent-to-agent rooms, persona engine, suffering system.
