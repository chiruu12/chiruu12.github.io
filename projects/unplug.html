Unplug [WIP]

Runtime security for AI agents

[site] [github]

// what it does

Defense layer for LLM agents. 3-stage pipeline (regex, ML classifier, LLM judge) that catches prompt injection, data leakage, destructive actions, and jailbreaks. Span-level redaction, not binary blocking. Ships as a Python SDK with a hosted API and MCP server coming next.

// why I built this

Every agent framework I tested (9 of them: LangChain, CrewAI, OpenAI Agents SDK, etc.) has zero built-in security. Agents can now execute code, query databases, and move money, but nothing sits between what an attacker tells the agent and what the agent does. Prompt injection has been OWASP's top LLM vulnerability for three years running.

// what makes it different

Taint tracking. Every piece of text carries metadata about where it came from (user input vs retrieved document vs tool output). This catches indirect injection, where a malicious instruction hidden in a document the agent reads drives a destructive tool call. Most scanners treat text in isolation. Unplug tracks the full execution graph.

// stack

Python SDK (pip install unplug). 245+ regex patterns across 15 languages, 12-stage text normalizer that beats evasion techniques (leetspeak, homoglyphs, base64, zero-width characters). ONNX classifier on CPU, no GPU needed. Planning to train a proprietary model on a synthetic dataset as threat data grows.

// what's next

Loading the ONNX classifier, publishing to PyPI, benchmarks against public datasets. Then framework integrations starting with Agno, and a hosted API for teams that don't want to self-host.
