ClipChain [WIP]

Agent-driven video pipeline on fal.ai

[github] (private for now)

// what it does

Chain short source clips into longer videos. The agent picks which clips to use, sequences them, and drives the render through fal.ai - no manual assembly in between.

// how it works

  • Skill: the playbook that tells the agent how to pick and order clips.
  • MCP server: the tool surface for fetching clips and kicking off renders.

// why I built this

Cutting short clips together into one longer video is the boring part of content work. It is exactly the kind of task that should be: describe what you want, let the agent assemble it, review the result.

// what's next

  • Open source it
  • More render backends behind the same skill
