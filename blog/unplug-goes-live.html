unplug goes live

May 2026

unplug-ai.org is live. Domain acquired, emails routed, site deployed on Cloudflare Pages. Unplug now has a home on the internet that isn't just a GitHub README.

// where the product stands

The SDK has about 3,100 lines of source code and 2,600 lines of tests. Five scanners (injection, destructive, leakage, harmful, financial), a 12-stage text normalizer that handles evasion techniques most tools ignore, and a taint tracking system that traces where every piece of text came from.

The architecture is solid. The problem is that nobody can use it yet. Not on PyPI, no CLI, no ML classifier loaded. Lots of well-written code sitting in a repo with zero stars.

// what's coming

The v0.2.0 plan is locked. Three weeks of work:

  • Fix 15 security bugs found during a thorough code review (a security product with known vulnerabilities is a bad look)
  • Load an ONNX classifier (ProtectAI DeBERTa) so it's not just regex
  • Build a CLI so you can run unplug scan "text" from a terminal
  • Publish to PyPI so anyone can pip install unplug
  • Write an Agno framework integration and submit a PR to their repo
  • Run benchmarks against public datasets and publish the numbers

After that: synthetic dataset creation for training a custom model, and releasing Unplug Tiny as a lightweight open-source classifier.

// the bet

AI agents are getting tool access. They can query databases, execute code, move money. Zero out of nine major agent frameworks have built-in security. Four standalone companies in this space got acquired for a combined $1.3 billion in the last year. The independent open-source position is open.

That's what Unplug is going after. Not a feature. A category.

Site is at unplug-ai.org. Code is at github.
